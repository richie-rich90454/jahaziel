# Brand asset inventory

Every SVG, PNG, and ICO in the upstream tree maps to a replacement of the
same dimensions. Files land here before the icon patch is authored.

| Upstream asset | Replacement | Dimensions |
|---|---|---|
| `resources/icons/code.png` | `icons/jahaziel-code.png` | 512x512 |
| `resources/icons/code.ico` | `icons/jahaziel-code.ico` | 256x256 |
| `resources/linux/code.png` | `icons/jahaziel-code-linux.png` | 512x512 |
| `resources/darwin/code.icns` | `icons/jahaziel-code.icns` | 1024x1024 |
| `resources/win32/code.ico` | `icons/jahaziel-code-win.ico` | 256x256 |

Workbench SVGs keep their filenames and view boxes; only the artwork
changes. No Microsoft trademarked asset ships.
