# Fonts

License-clean replacements for the upstream workbench fonts.

| Original | Replacement | License |
|---|---|---|
| Cascadia Code | JetBrains Mono | OFL 1.1 |
| Cascadia Mono | JetBrains Mono NL | OFL 1.1 |
| Segoe UI (workbench) | System font stack | Various |

Drop the OFL-licensed TTF files into this directory; the icon patch
references them by filename. Nothing else in the tree changes.
