# Naming

The project is named **Jahaziel** (יַחֲזִיאֵל), a Levite of the sons of
Asaph, upon whom the Spirit of the LORD came in the midst of the assembly
(2 Chronicles 20:14). When Judah stood before a vast enemy alliance with no
plan and no strength, Jahaziel stood and spoke: *"Do not be afraid nor
dismayed because of this great multitude, for the battle is not yours, but
God's"* (2 Chronicles 20:15). The platform stands in the assembly the same
way: one login and one browser tab giving developers a real Linux machine, a
real IDE, a real terminal, real isolation, real audit, and real
infrastructure. The project has one name; everything inside is named for
what it does, in plain English.
