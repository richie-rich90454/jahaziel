# IDE patch manifest

One coherent change per patch, applied in order by `ide/build.sh`. The
stack must apply cleanly to the pinned upstream tag; `build.sh` fails
closed when a patch does not.

Upstream is pinned by `ide/upstream-version.txt` and checked out to the
gitignored `ide/upstream/` by `ide/build.sh` with
`git clone -c core.autocrlf=false --depth 1 --branch <tag> https://github.com/microsoft/vscode.git upstream`
(the `-c` flag keeps LF endings for `git apply` on Windows checkouts).
Patch 0002 is generated by `ide/scripts/rebrand.py --upstream ide/upstream`
and captured with `git -C ide/upstream diff`. The stack is checked with
`ide/tests/patch-smoke.sh ide/upstream`, which must pass before a build.
