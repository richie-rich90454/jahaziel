# IDE patch manifest

One coherent change per patch, applied in order by `ide/build.sh`. Patches are
rebased onto each new upstream stable tag. Security-relevant patches need two
approvals.

Upstream is pinned by `ide/upstream-version.txt` (currently tag `1.94.0`) and
checked out to the gitignored `ide/upstream/` by `ide/build.sh` with
`git clone -c core.autocrlf=false --depth 1 --branch <tag> https://github.com/microsoft/vscode.git upstream`
(the `-c` flag keeps LF endings for `git apply` on Windows checkouts).
Patch 0002 is generated by `ide/scripts/rebrand.py --upstream ide/upstream`
and captured with `git -C ide/upstream diff`. The stack is proven with
`ide/tests/patch-smoke.sh ide/upstream` (28 checks: must pass, fails on a
pristine checkout).
